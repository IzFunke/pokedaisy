# Known Issues and Limitations

- Pokémon Y now boots on the Galaxy S25 Ultra to its logo/intro after the user selected and confirmed German (about 59.8 FPS / 100% in the observed session). A process restart before the game reached save setup returned to language selection, so the language choice has not been proven persistent. Gameplay compatibility, audio, save persistence, broader controls, and stability remain unverified.
- Physical hardware app startup, JNI/Android setup, Pokémon Y title boot, rendering, and D-pad navigation are verified. Audio, save handling, broader controls, and stability are not yet verified.
- The Azahar loader recognizes 3DSX homebrew, but PokeDaisy's current game entry path accepts only decrypted supported retail NCSD carts. No homebrew test harness or content is currently wired through the app.
- Production/device builds package Azahar for `arm64-v8a`. An opt-in `-Ppokedaisy.n3dsX86_64=true` build now runs 3DS games on the x86_64 API 36 AVD for runtime checks; this is an emulator-only build path, not the default Dev/release ABI set. The old translation AVD still crashed with SIGILL.
- The full app unit suite completes with 4,194 tests, 17 failures and 59 skips; focused 3DS routing and single-screen screenshot suites pass. See `TEST_RESULTS.md` for exact failure classes.
- Azahar's native binary makes the optional APK large. Review size/performance before release.
- Some historical notes in `docs/3DS_GAMES_PLAN.md` describe earlier device-validation status; they are dated and remain as historical context. Current device evidence is summarized in `PROJECT_STATUS.md` and `TEST_RESULTS.md`.
- Ultra Moon reached its first player-profile photo question in German on the Galaxy S25 Ultra at about 30 game FPS / 100% speed. Ultra Sun is recognized by tests but has not had a device boot check. Neither Ultra title has a verified companion RAM map; companion polling is intentionally disabled until title-specific addresses are verified. Ultra Moon's current session has not reached an in-game save or been restarted after the language selection.
- `ONE SCREEN` closed/open/closed behavior is visually verified on the x86_64 API 36 emulator with Pokémon Y at its language prompt: top-only while closed, actual 4:3 touch surface while open. API 36's explicit `SurfaceView` composition order fixes the leak that parent/view alpha alone did not. This exact hide behavior has not been verified below API 36, nor on the S25 during this follow-up.
- Ultra Sun has identity and launch routing, but no Ultra Sun ROM is available for a runtime check and its existing-save metadata format remains unmapped. Do not synthesize metadata for an unrecognized Ultra Sun save until live evidence is available; a clean game can still create its own save.
- Importing private preferences from the installed official package is blocked: it is a non-debuggable app with `allowBackup=false`. Dev's own preferences are preserved by `adb install -r`; Android does not permit reading the official package's private SharedPreferences on this unrooted device.
- The current Pokémon Y x86_64 run confirmed the user-authorized German choice and stopped at `Begin game` / `Select language`, before any personal setup. Persistence across a process restart is unverified. This was emulator evidence, not an S25 Ultra run. The Android ARM64 AVD cannot start on this x86_64 Windows host.
